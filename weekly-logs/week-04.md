## 踩坑笔记

**单片机（都是真金白银踩出来的）**
- **"编译 0 错误" ≠ 编对了程序**：第一次编的是 10-14 那个空工程，输出 `led.hex`。判据是**看 hex 输出文件名**（02-1 应输出 `Project`）
- **换 USB 口 = 换 COM 号**：Windows 按"设备 + 端口"记忆，COM3 变 COM4，STC-ISP 不点「扫描」就永远对着不存在的口喊
- **拔插 USB 会错过握手窗口**：CH340 重枚举要 1–2 秒，bootloader 只监听上电后几十毫秒 → 正确做法是**USB 线不动，用板上 POWER 开关断电**
- **数码管一直亮一个"8"不是故障**：程序没驱动 P0 段码和位选，浮空高电平导致
- **CH340 驱动 Windows 会自己装**，不必先下驱动包

**学习方法**
- 我的错误模式是**跳步**，不是不会：代入只看分子、换元漏系数、算到一半停。对策定成硬规矩——**一行一步 + 代数算完必须数字验算**
- **零基础不要直接上"位运算"这类抽象练习**，先跑通"写→编译→运行"这条链
- **板子到货的 90 分钟只做一件事**：点亮。顺手感往下学 = 三头都要，一个都成不了
